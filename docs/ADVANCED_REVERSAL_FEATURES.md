# 高级反转特征工程设计文档

## 概述

FreqAITest_Advanced 策略采用**6层深度特征系统**，从统计学和物理学角度精确捕捉市场反转信号。

---

## 🔴 第1层：市场极端状态检测（统计极值）

### 1.1 Z-Score 标准化

**核心思想**：将指标标准化为"距离均值多少个标准差"

```python
Z-Score = (当前值 - 均值) / 标准差
```

**反转信号**：
- Z-Score < -2：超卖（低于均值2个标准差）
- Z-Score > +2：超买（高于均值2个标准差）

**特征**：
- `rsi_zscore`: RSI的Z-Score
- `price_zscore`: 价格的Z-Score

**优势**：
- ✅ 动态适应市场波动率
- ✅ 统计学严格定义的"极端"
- ✅ 可跨时间框架比较

---

### 1.2 综合超买超卖评分

**公式**：
```python
extreme_score = (RSI_score + MFI_score + CCI_score) / 3

其中：
RSI_score = (RSI - 30) / 40 * 100  # 30-70映射到0-100
MFI_score = (MFI - 30) / 40 * 100
CCI_score = (CCI + 100) / 200 * 100  # -100到+100映射到0-100
```

**解读**：
- 0-30分：超卖区域（底部反转候选）
- 70-100分：超买区域（顶部反转候选）
- 40-60分：中性区域（无明显极端）

**优势**：
- ✅ 多指标交叉验证
- ✅ 降低单一指标误判
- ✅ 量化极端程度

## 🔴 第2层：多阶动量衰减分析（牛顿力学类比）

### 2.1 物理学视角

在物理学中：
- **位置** → 价格
- **速度**（一阶导数）→ 价格变化率（动量）
- **加速度**（二阶导数）→ 动量变化率

### 2.2 一阶动量（速度）

```python
momentum_1st = close.pct_change(period)
```

**含义**：价格涨跌速度

### 2.3 二阶动量（加速度）⭐ 核心

```python
momentum_2nd = momentum_1st.pct_change(period/2)
```

**核心反转逻辑**：

| 一阶动量 | 二阶动量 | 市场状态 | 反转信号 |
|---------|---------|---------|---------|
| 正（上涨）| 负（减速）| **上涨动能衰减** | 🔴 顶部反转 |
| 负（下跌）| 正（减速）| **下跌动能衰减** | 🟢 底部反转 |
| 正（上涨）| 正（加速）| 上涨加速 | ⚪ 趋势延续 |
| 负（下跌）| 负（加速）| 下跌加速 | ⚪ 趋势延续 |

**实例**：
```
时间  价格  一阶动量  二阶动量  状态
T1    100   +3%       -       上涨
T2    103   +2%      -33%     上涨但减速 ← 顶部反转预兆
T3    105   +1%      -50%     继续减速  ← 反转确认
T4    106   -1%      -200%    转为下跌  ← 反转完成
```

**特征**：
- `momentum_1st`: 速度
- `momentum_2nd`: 加速度（最重要）
- `momentum_decay`: 加速度（负值=衰减）

---

### 2.4 动量比率

```python
momentum_ratio = short_momentum / long_momentum
```

**反转信号**：
- 比率 > 1.5：短期动量远超长期 → 可能过度延伸
- 比率 < 0.5：短期动量远低长期 → 动量衰减

## 🔴 第3层：趋势疲劳度量

### 3.1 距离极值

```python
dist_from_high = (period_high - close) / close
dist_from_low = (close - period_low) / close
```

**反转逻辑**：
- `dist_from_high < 2%`：接近周期最高点 → 顶部反转风险
- `dist_from_low < 2%`：接近周期最低点 → 底部反转机会

---

### 3.2 ADX 衰减

```python
adx_decay = ADX.pct_change(period/4)
```

**含义**：
- ADX上升：趋势增强
- ADX下降：趋势衰竭 → 反转前兆

**反转信号**：
- ADX > 25 且 adx_decay < -10%：强趋势衰竭 → 高概率反转

---

## 🔴 第4层：成交量异常检测

### 4.1 成交量 Z-Score

```python
volume_zscore = (volume - volume_mean) / volume_std
```

**反转确认**：
- Z-Score > 2：异常放量（2倍标准差）
- 配合极端价格 → 恐慌或贪婪高潮 → 反转确认

---

### 4.2 成交量分位数排名

```python
volume_percentile = volume在过去N根K线的排名百分比
```

**解读**：
- 90%以上：成交量处于历史前10% → 异常活跃
- 10%以下：成交量处于历史后10% → 过度平静

**反转信号**：
- 价格极端 + 成交量 > 90% → 强反转确认

---

## 🟡 第5层：背离检测

### 5.1 价格 vs RSI 背离

```python
price_rsi_divergence = price_change - (rsi_change / 100)
```

**正背离（底部反转）**：
- 价格创新低（-5%）
- RSI不创新低（-2%）
- divergence = -5% - (-2%) = -3% （负值）
- → 卖压减弱，底部反转信号

**负背离（顶部反转）**：
- 价格创新高（+5%）
- RSI不创新高（+2%）
- divergence = +5% - (+2%) = +3% （正值）
- → 买压减弱，顶部反转信号

---

### 5.2 价格 vs MACD 背离

类似原理，验证动量指标与价格的背离度。

## 🟡 第6层：波动率突变

### 6.1 ATR 突变系数

```python
atr_spike = ATR.pct_change(period/4)
```

**反转信号**：
- ATR突然上升 > 50%：波动率剧增 → 恐慌/贪婪高潮
- 配合极端价格 → 反转确认

---

### 6.2 波动率比率

```python
volatility_ratio = current_ATR / historical_avg_ATR
```

**解读**：
- 比率 > 2：当前波动率是历史平均的2倍
- 极端波动往往发生在反转点

## 🎯 综合反转信号强度（复合指标）

### 公式

```python
reversal_signal_strength =
    extreme_score * 0.4 +       # 40%权重：极端状态
    momentum_score * 0.4 +      # 40%权重：动量衰减
    volume_score * 0.2          # 20%权重：成交量确认
```

### 权重设计原理

1. **极端状态（40%）**：
   - 最基础的反转前提
   - 没有极端就谈不上反转

2. **动量衰减（40%）**：
   - 反转的核心驱动力
   - 二阶动量是最强信号

3. **成交量确认（20%）**：
   - 辅助验证
   - 降低假突破风险

### 评分解读

| 分数 | 反转可能性 | 建议操作 |
|------|----------|---------|
| 0-30 | 极低 | 观望 |
| 30-60 | 中等 | 谨慎 |
| 60-80 | 较高 | 可考虑 |
| 80-100 | 极高 | 高确定性 |
